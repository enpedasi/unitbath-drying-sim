# UB Airflow Studio

ユニットバス内に干した洗濯物と空気の流れを、室外から観察する3Dブラウザーアプリです。

## 起動

Node.js 22.12以降を使用してください。

```sh
npm install
npm run dev
```

表示されたローカルURL（通常 `http://localhost:5173`）を開きます。

```sh
npm test         # 流量保存、境界、条件の変化を検証
npm run build    # TypeScriptの検査と本番ビルド
npm run preview # dist のプレビュー
```

## 操作

- UBサイズ：3畳（1.8 × 2.7 m）／4.5畳（2.7 × 2.7 m）、天井高2.25 m
- ポールの洗濯物：0〜12枚
- スライド戸：0〜100%、5%刻み
- 室外サーキュレーター：ON／OFF、送風速度0.5〜3.0 m/s、左右−40〜40°、上向き0〜45°。換気扇は常時ON
- 左ドラッグで回転、右ドラッグで移動、ホイールで拡大縮小
- タッチでは1本指で回転、2本指で移動・拡大縮小
- クォーター／俯瞰／正面、ズームボタン、視点リセット
- 全体矢印（初期表示）／流線／軌跡／粒子表示、風速／回転の強さの着色、一時停止、再生倍率、計算リセット、気流非表示、透過壁の切り替え
- 全画面表示、3DキャンバスのPNG保存

計算はWeb Workerで継続します。送風のON/OFF・速度・方向を変更しても、それまでの速度場と時刻を保ちます。サイズ・衣類数・戸の開度の変更時は形状が変わるため、新しいWorkerで0秒から計算します。古いWorkerは破棄し、古い結果の混入を防ぎます。

一時停止は計算の進行要求・矢印・粒子・時計を停止します。停止直前に開始した1件の計算結果は、再開するまで表示しません。倍率は計算と表示に共通です。計算負荷が高い場合は進行を遅くし、時計や粒子だけを先に動かしません。時計は計算上の経過時間を示します。

3D表示はWebGL 2対応ブラウザーが必要です。フォントのみGoogle Fontsを参照しますが、取得できない場合はシステムフォントへフォールバックします。

## 計算モデル

**非定常・非圧縮のNavier–Stokes方程式を、約11.25 cmのMAC格子で近似**します。格子面に速度、格子中心に圧力を置き、次の処理を各時間ステップで行います。

1. 速度自身による運動量の移流。全領域で一次の半ラグランジュ法を使用し、出発点周囲の速度を三線形補間します。従来のMacCormack高次補正は、境界付近で無効にしても内部で長時間後に速度を増幅するケースがあったため除去しました。一次補間には数値拡散があり、細かい渦を弱める影響があります。
2. 粘性、衣類の抵抗、サーキュレーターの局所的な駆動力。
3. 有限体積法の圧力補正で非圧縮条件を回復。Poisson方程式を修正不完全Cholesky前処理付き共役勾配法（MIC-PCG）で解く。

最大時間刻みは0.04秒。格子面の最大速度に応じてCFL数が0.75以下になるよう細分化します。サーキュレーターの力は**室外のファン円盤の周辺だけ**に作用し、室内へは移流・圧力を通じて伝わります。あらかじめ室内に噴流の形を置く処理、人工的な渦、vorticity confinementはありません。

風を止めた瞬間に速度場はゼロになりません。既存の流れが移流・拡散・抵抗・換気の影響を受けて変わっていきます。初期状態は換気扇による給気流で、サーキュレーターの流れは0秒から発達します。

## 境界・パラメーター

- 外部空間の端は環境圧。領域外から入る運動量は静止した周囲の空気と補間し、端の速度を再利用して自己増幅することを防ぎます。圧力補正により給気流量を確保します。換気口を除く壁・床・天井・浴槽への法線方向の流量はゼロです。粘性項では固体側の速度をゼロとします。
- 天井の換気口は3×3格子面（33.75 cm角）の流出口です。排気量を開口面積で割った上向き速度を指定し、その面を通る流量を含めて圧力補正します。開口直下を含む室内の各セルでは流入量と流出量を一致させ、空間中で体積を除去しません。換気扇は常時ONで、ラベルの排気量は計算面を通過する流量です。開口の位置・寸法は表示と計算で共有します。格子に合わせた仮定の開口で、実機の有効開口面積ではありません。
- 排気量は `90 × (0.22 + 0.78 × √(開度 / 100)) m³/h` と仮定。閉時19.8 m³/h、全開時90 m³/h。実機の性能曲線ではありません。
- 閉じた戸には15 mmのアンダーカットを仮定。格子より細い開口は通過面積比で表現します。
- 衣類は格子内の多孔質抵抗として速度を減衰させます。係数は比較用の仮定で、実測による同定はしていません。
- 空気の動粘性係数は約 `1.5×10⁻⁵ m²/s`。格子より小さい運動には数値拡散の影響もあります。
- 送風速度は局所的なファン駆動の目標速度であり、実機の測定値や室内一様速度ではありません。羽根の旋回は力として与えていません。

## 表示と解釈

- 「全体矢印」を初期表示とします。UBと戸の前の空間に33.75 cm間隔の3D格子で観測点を置き、固体内の点を除外します。位置や本数を風速・換気口からの距離で変えません。灰色の点は観測位置で、ほぼ無風でも残します。各点から計算風向へ短いガイド線を引き、その上を矢印が風速に比例して移動します。微風を見やすくするため、移動は計算時間に対して一律10倍の表示です。無風では動きません。観測点付近でフェードして繰り返す局所的な風向・風速表示であり、部屋を横断する空気塊の軌跡ではありません。各点の位相をずらし、給排気口への表示の集中を防ぎます。ガイド長は微風でも読める表示尺度を使い、壁や天井では短くします。色は選択した実風速または渦度です。速度場・時計・粒子の物理速度は変えません。風向・風速の読み直しは最大4回/秒、矢印の移動は描画フレームごとに計算時間の進行分だけ更新し、一時停止・再生倍率に追従します。
- 「流線」は現在の速度場を固定して、風向に沿って上流・下流へ積分した線です。開始点は同じ表示範囲に56.25 cm間隔で均等配置し、換気口や戸専用の追加点は置きません。線上の矢印は下流方向を示します。曲線の重なりや長さで線の密度は変わるため、局所比較には全体矢印を使います。粒子の移動履歴や未来の流れの予測ではありません。格子幅の0.35倍を基本の積分距離とし、固体の手前で細分化・停止し、換気口では開口面まで線をつなぎます。更新は最大1回/秒で、一時停止中は同じ速度場を表示します。
- 粒子は計算した速度場に沿って同じ計算時間で移動します。軌跡は48点で直近の移動を示し、長時間待っても全履歴は蓄積しません。遅い流れでは短い線になるため、全域の風向は「全体矢印」、通り道は「流線」で確認します。
- 描画の速度補間には計算時のMAC格子面速度を使います。閉じた壁面での法線速度をゼロに保ち、天井の開口面では指定した排出速度へ補間します。開口端の速度を閉じた天井へにじませません。排気終了は粒子の移動線分が実際の開口面を横切った時に判定し、手前の空間で消去しません。
- 軌跡・粒子は動きを見るための補助表示です。表示範囲の等体積の空気セルから選び、初期配置を空間全体へ分散させ、再配置も同じ範囲から一様に選びます。換気口直下・戸前の特別枠と、低速だから10秒で消す処理を廃止しました。最下段は描画上の床に隠れるため配置対象から外します。排出された軌跡は開口上の終点を計算時間で0.6秒保持してから再配置します。最大寿命は300秒です。固体を横切る粒子は再配置し、移動量に応じた細分化と線分全体の検査で壁を飛び越えるのを防ぎます。移動後の粒子分布は必ずしも均一ではなく、粒子の密度は流量を意味しません。
- 「風速」の色は0〜0.8 m/s。「回転の強さ」は速度場のcurl（渦度）の大きさ、0〜3 s⁻¹で着色します。凡例上限を超える値は上限色です。
- 渦度は局所的な回転・せん断の指標です。高い渦度だけで、部屋全体の一つの渦や乾燥性能を判断することはできません。
- 時間が経過すれば壁に沿って一周する循環が必ずできるとは限りません。壁際で向きが変わる流れと、室内全体を一方向に回る流れは区別して観察してください。
- 平均風速・滞留割合・平均渦度は、浴槽等の固体を除くUB内の空気領域を対象とします。換気回数は排気量÷UBの幾何学的容積です。

## 検証と限界

数値テストでは流量保存、固体境界、時間とともに伝わる送風、送風停止後の慣性と減衰、方向変更、時間刻みの感度を確認しています。渦度は一様流および剛体回転の解析解と比較します。Workerの一時停止・再開、古い結果の排除も回帰テストに含めています。

`tests/streamlines.test.ts` では、弱い一様流・回転する解析場・静止場、表示用速度の壁面法線成分、固体の角を横切る経路、衣類3枚・戸5%・送風なしの流線を検証します。

`tests/sampling.test.ts` では、両サイズでの矢印・流線の全域等間隔配置、無風・微風でも観測点数を維持すること、風向・風速の保持、矢印の壁貫通防止、粒子の配置セルを等しく選ぶことを検証します。

`tests/vectorMotion.test.ts` は矢印の移動距離と風速の比例、無風・一時停止、風速更新時の位相維持、時間刻み・再生倍率、繰り返し時の境界と全域の観測位置の維持を検証します。

`tests/stability.test.ts` は各条件で60秒の計算を継続します。初期設定、戸5%・強風、4.5畳・衣類12枚・全開と途中の送風変更、4.5畳・衣類なし・全閉を対象に、風速の異常増大と流量保存を検査します。`npm test` に含まれます。計算量が多く、実行環境によって10分以上かかります。

`tests/ventilation.test.ts` は3畳・衣類0枚・戸15%・初めから送風OFFで6分24秒まで進め、室内と外部の速度の異常増幅、流量保存、非有限値を検査します。短時間の収束・有限値チェックだけでは見逃していた、5分前後で室内に細かい乱れが広がる不具合の回帰テストです。速度のしきい値はこの条件での回帰検出用であり、実測値との一致を保証するものではありません。

`tests/exhaust.test.ts` は両サイズ・戸0/10/15/100%で、開口面を通過する流量と給気量の一致、開口直下でも体積を除去しないこと、閉じた天井に速度が漏れないこと、粒子と流線が開口面まで到達することを検査します。`tests/exhaust-stability.test.ts` は3畳・衣類0枚・戸10%・送風OFFで12分まで計算し、報告された11分26.2秒も含めて排気流量・安定性・換気口への粒子の到達を確認します。全テストの所要時間は実行環境によって20分以上になる場合があります。

計算が異常終了した場合は、非有限値・速度上限超過・圧力補正の誤差・Worker実行障害を区別して表示します。発生時の条件、時刻、診断値は「直前の計算エラーの詳細」に残り、JSONとして保存できます。「再試行」は0秒から計算を作り直し、エラー前の再生／一時停止状態に戻します。

換気・送風による流れの時間変化を比較するための粗い格子のモデルです。**格子より細かい乱流を解像したDNSや、実測検証済みの設備設計用CFDではありません。** 格子収束性、乱流モデル、実機との照合は未検証です。温湿度・浮力・蒸発・乾燥時間・布の変形は対象外です。

- 型・寸法・補間：`src/simulation/model.ts`
- 非定常ソルバー：`src/simulation/transient.ts`
- Workerと進行制御：`src/simulation/flow.worker.ts` / `session.ts`
- 表示：`src/scene/SceneEngine.ts` / `src/App.tsx`、等間隔の観測点・粒子配置：`src/scene/sampling.ts`
